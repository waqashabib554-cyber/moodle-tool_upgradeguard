# Contributing

Bug reports and focused improvement proposals are welcome through the public
issue tracker once this repository has been published. Before opening an issue,
check for an existing report and use the supplied templates.

Please do not post credentials, personal data, private site details, or
unredacted scan exports. Report suspected security vulnerabilities through the
private reporting instructions in `SECURITY.md`, not through a public issue.

Changes should follow Moodle coding conventions, include appropriate PHPUnit
coverage, and preserve compatibility with the Moodle versions declared in
`version.php`. Please describe the Moodle/PHP/database versions used to test a
change.

Contribution review and response times are not guaranteed. No service-level
agreement is offered by this repository.
