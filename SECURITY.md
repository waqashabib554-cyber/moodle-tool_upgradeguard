# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. After this
repository is published, use **Security → Report a vulnerability** to send a
private report. The repository owner must enable GitHub private vulnerability
reporting before this channel is available.

Do not include passwords, tokens, private site URLs, personal data, or
unredacted Moodle scan exports in a report.

## Supported versions

Security support for released versions has not yet been formally defined.
Until the maintainer publishes a policy, report concerns privately and include
the affected Upgrade Guard version and Moodle version, without disclosing
exploit details publicly.
